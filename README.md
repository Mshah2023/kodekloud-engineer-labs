
# KodeKloud Engineer Labs

This repository documents my hands-on work from the **KodeKloud Engineer learning path**.
Each lab simulates real-world DevOps tasks performed within the fictional company **xFusionCorp Industries** as part of **Project Nautilus**.

The goal of this repository is to:

* Practice real DevOps and Cloud engineering tasks
* Document solutions to KodeKloud Engineer labs
* Build a structured DevOps learning portfolio
* Improve Linux, Kubernetes, Cloud and automation skills

---

# Project Nautilus

Project Nautilus is operated by the Naval subdivision of **xFusionCorp Industries**.
The Nautilus application helps naval forces make procurement decisions for maritime systems while ensuring operational efficiency and cost reduction.

The application follows a **three-tier architecture** deployed in the **Stratos Datacenter (North America)**.

### Architecture

**Client Tier**

* Web browser accessing the Nautilus application

**Application Tier**

* Linux
* Apache
* PHP
* Application servers

**Data Tier**

* MariaDB relational database

**Load Balancer**

* Nginx distributing traffic to application servers

**Shared Services**

* NAS Storage Server
* SFTP File Transfer Server
* Backup Server
* Jump Host for secure infrastructure access
